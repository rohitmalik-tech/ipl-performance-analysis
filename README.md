# 🏏 IPL Performance Analysis

An interactive **Power BI dashboard** exploring IPL match and player data from **2008–2025**, delivering deep insights into team performance, player statistics, and season-wise trends.

## 📌 Overview

This project analyzes 18 seasons of IPL cricket data (2008–2025) to uncover team and player performance trends, presented through a clean, interactive Power BI dashboard.

## ✨ Key Features

- 🧢 **Orange Cap Tracker** — Top run-scorer of each season
- 🎯 **Purple Cap Tracker** — Top wicket-taker of each season
- 🔢 Total **fours, sixes, and centuries** tracked across seasons
- 📊 **Live Points Table** — Matches played, won, lost, Net Run Rate (NRR), and total points
- 🏆 **Season Summary** — Highlights the season winner and runner-up
